# Stack Visualization - UAS Struktur Data

Aplikasi pembelajaran Stack (LIFO) dengan visualisasi interaktif. Backend Flask + Frontend HTML/CSS/JS.

## 📁 Struktur Project

```
tugasuasstrukturdata/
│
├── backend/              # Backend Flask
│   ├── app.py           # Main Flask application
│   └── requirements.txt  # Python dependencies
│
├── frontend/            # Frontend HTML/CSS/JS
│   ├── index.html       # Main HTML file
│   ├── script.js        # JavaScript logic
│   └── style.css        # Styling
│
├── docs/                # Documentation
│   ├── DOKUMENTASI.md   # Dokumentasi lengkap
│   ├── API_REFERENCE.md # API endpoints
│   ├── USER_GUIDE.md    # Panduan pengguna
│   └── ... (file docs lainnya)
│
├── .gitignore           # Git ignore file
└── README.md            # File ini
```

## 🚀 Quick Start

### 1. Install Dependencies
```powershell
cd backend
pip install -r requirements.txt
```

### 2. Run Server
```powershell
cd backend
python app.py
```

### 3. Open Browser
```
http://127.0.0.1:5000
```

## 📝 Stack Operations

- **Push** - Add element to top of stack
- **Pop** - Remove element from top of stack
- **Peek** - View top element without removing
- **Clear** - Remove all elements
